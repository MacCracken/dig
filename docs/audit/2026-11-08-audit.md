# dig P(-1) audit — 2026-11-08 (0.5.1 → 0.5.2)

A pre-release adversarial audit of everything dig ships except the AGNOS
backend (`src/platform_agnos.cyr`), whose review is parked by owner direction
(roadmap.md § AGNOS-arm review). The repairs are in 0.5.2; the user-facing
summary is CHANGELOG.md § 0.5.2.

## Method

Five independent reviewers each took one lens over the 0.5.1 tree, working in
their own scratch copies, with every finding to be shown by a concrete input:

| Lens | Scope |
|---|---|
| Wire parsing / memory safety | dns.cyr, tcp.cyr framing, reply indexing in query/output. 300k fuzz frames placed against a PROT_NONE guard page, through every parser and printer. |
| Protocol / spoofing | query.cyr, tcp.cyr, EDNS, acceptance, retry/timeout, exit codes, against RFC 1035 / 6891 / 7766 / 5452 and BIND 9.18 source. |
| CLI / local input / output | cli.cyr, main.cyr, resolv.cyr, output.cyr; crafted argv, resolv.conf bind-mounted in a mount namespace. |
| Platform / syscalls / resources | platform_linux.cyr, fd lifecycle, time, EINTR, SIGPIPE, aarch64 under qemu. |
| Refactor / performance / tests | duplication, stale comments, syscall counts, benches, and mutation of the existing guards. |

Every network finding was reproduced against the 0.5.1 binary with a scripted
DNS server on 127.0.0.1:53 inside `unshare -rn`. That rig is now the
integration suite, `tests/integration/net.sh`: on the 0.5.1 binary 42 of its
68 checks fail, on 0.5.2 all pass, on x86_64 and on aarch64 under qemu.

Every repair has a test, and every such test was mutation-checked: the repair
was reverted in a scratch copy and the suite had to fail. 43 mutants were run,
including the 14 the refactor reviewer found surviving against pre-existing
guards. Three of the 43 survived at first (escape chunking, empty TXT,
TCP-read EINTR); each got a sharper test, and all 43 are now killed.

## Findings

Severity: P1 = a wrong or forged answer reported as success, or terminal
injection; P2 = a real defect with limited impact; P3 = robustness, parity,
diagnostics, hardening. "Lenses" counts the reviewers who found it independently.

### P1

| Id | Finding | Lenses | Disposition |
|---|---|---|---|
| A1 | On the TC=1 → TCP fallback, the TCP read went straight into the buffer holding the accepted UDP reply. A TCP reply that then FAILED acceptance (wrong ID, wrong question, QR clear) or was cut short was printed as the answer, against the UDP length, exit 0. A hostile server bypassed every RFC 5452 check. | 4 | Fixed: both transports receive into private scratch; `query_commit_reply` copies into `rx` only after acceptance. |
| A2 | TC=1 with a failed TCP retry exited 0; under `+short` it was silent, so an answer truncated to nothing looked like NODATA. A firewall blocking TCP/53 suffices. | 3 | Fixed: stderr warning in both modes, exit 9 (BIND exits 9 too). |
| A3 | Unknown `+options` were accepted in silence: `+norecurse` still sent RD=1, `+cd` set nothing, `+trace` ran a plain query, `+shrt` gave full output. Exit 0. | 2 | Fixed: usage error naming the option, exit 1, as BIND. |
| A4 | The query name from argv reached the terminal raw (banner, QUESTION line, illegal-name error): `dig $'x\e]0;PWNED\a...'`. Wire data was already escaped. | 3 | Fixed: every argv echo goes through the RFC 1035 §5.1 escaper. |

### Closed carried items

- **The 0.4.0 "stack slot overlapping a parameter" miscompile** was not a
  compiler bug. Before cyrius 6.6.18 the stdlib's `fmt_int_buf` always wrote 24
  bytes (CYRIUS-2026-0028), so `ipv4_format_to_buf` into a 16-byte buffer put
  its first digit at buf+23 — byte 7 of the next slot, giving exactly
  `0x3800000000000001`. Reproduced with the old body inlined; 6.7.18 is clean.
- **"No stdlib sendto / nanosleep / clock_gettime"**: closed since 6.6.20
  (`sys_sendto`, `sys_nanosleep`, `clock_now_ns`, `sleep_ms`); dig now uses
  `clock_now_ns`. There is still no named `SYS_CLOCK_GETTIME`.

## Refactor and optimization

Each change was shown byte-identical in output on 91 fixtures (stdout, stderr,
the combined `2>&1` stream and the exit code), against the pre-change binary.

- **Buffered stdout**: one write(2) for a normal answer (27 → 2 syscalls for
  `dig example.com` counting the query send, 110 → 2 for a TXT answer, 48 → 1
  for `-h`), stdout flushed before every stderr write so ordering holds.
- **Dead-code elimination on every build** (`[build] dce = true`): x86_64
  241,056 → 103,032 B, AGNOS 257,904 → 107,608 B. aarch64 NOP-fills.
- One answer-printing loop instead of two; one rdata name helper instead of
  seven copies; one CLI compare helper instead of two (20 hand-counted literal
  lengths gone); the TCP frame read split out so it can be tested.
- Stale comments corrected across src/ (OPT "not parsed yet", /dev/urandom,
  "no sendto wrapper", the footer diagnosis, misplaced doc blocks, and others).
- Considered and rejected: merging the name decoder and walker (+20% on a
  59-record walk; a fuzz assertion that they agree gives the same protection),
  named registry offsets (+232 B at 6.7.18).
